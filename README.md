
# My Web - PHP CRUD

Project CRUD sederhana menggunakan PHP Native dan MySQL.

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP Native
- PDO
- MySQL
- Vercel
- Railway

## Project Structure

- Frontend: Vercel
- Backend API: Railway
- Database: Railway MySQL

## API Endpoints

| Method | Endpoint | Fungsi |
|---|---|---|
| GET | /api/index.php | Menampilkan data |
| POST | /api/index.php | Menambah data |
| PUT | /api/index.php | Mengubah data |
| DELETE | /api/index.php | Menghapus data |

## Environment Variables

DB_HOST=
DB_PORT=
DB_NAME=
DB_USER=
DB_PASS=
FRONTEND_URL=

## Deployment

Frontend dideploy melalui Vercel.

Backend dideploy melalui Railway menggunakan Dockerfile.

Database menggunakan MySQL di Railway.
